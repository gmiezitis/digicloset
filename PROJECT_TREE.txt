Key Features Implemented
=========================

✅ Splash + Boot
   - Custom animated splash screen
   - Asset preloading with strict mode guard
   - Minimum display duration + graceful error logging

✅ Navigation & Shell
   - Bottom tab navigator with icons + theming
   - Closet/Add Item screens wired to services
   - Placeholder stubs for future Planner/Outfit/Profile

✅ Design System
   - Color palette, spacing, typography, shadows, radii
   - Tokens consumed across screens/components

✅ Local-First Data Layer
   - Storage abstraction with optimistic revisions
   - Closet store with hydration + telemetry logging
   - Draft sync queue with exponential backoff + snapshot listeners

✅ Camera & Cleanup Foundation
   - CameraService interface with capture persistence + events
   - Background cleanup queue + uploader proxy
   - Capture processing hook exposing queue status

✅ Closet UX
   - Sync summary with pending/synced/failed metrics
   - Draft cards surface queue retries and manual retry affordances
   - Item cards show sync state with friendly messaging
